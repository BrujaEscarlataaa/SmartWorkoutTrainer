# SmartWorkoutTrainer
An open-source personal fitness trainer to plan workouts, track training sessions, manage schedules, and monitor fitness progress.

## Tester l'application

En ligne : https://brujaescarlataaa.github.io/SmartWorkoutTrainer/

En local : `py -m http.server 8080` dans le dossier, puis ouvrir http://localhost:8080.
Tests de la logique : `node test.js`.
